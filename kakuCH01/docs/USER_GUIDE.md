# 使用说明

基本流程：**设置保存目录和模型目录 → 下载小说 → 提取术语表 → 翻译 → 回到首页阅读**

## 二、 下载小说

**1.在「设置 → 目录 → 保存根目录」中选择保存文件夹。**

**2.下载**

1. 点击左侧「下载」。点击上方支持站点按钮会通过系统默认浏览器打开对应网站。
2. 打开要下载的作品，复制作品链接，粘贴到输入框。
3. 点击「获取章节」，等待目录加载。
4. 勾选需要的章节，再点击下载按钮。
5. 下载完成后回到「首页」，点击书籍进入详情和章节目录。

「网站」页面为カクヨム（角川小说）的网站，可以直接查找、下载

   下载页提供カクヨム、Pixiv、エブリスタ、NOVEL DAYS、ノベルバ、ソリスピア的入口。支持的具体链接和可获取内容以页面返回结果为准：需登录、付费、已删除或被网站限制的章节可能无法下载。

## 三、 使用模型翻译

   省流：在翻译界面点击添加书籍，用qwen翻译提取术语，在书籍界面打开术语表启动qwen术语表，然后用Murasaki或sakura翻译

### 1. 提取术语

   术语表按小说分别保存。进入书籍详情，点击「打开术语表」，可以查看人工术语表和 Qwen 术语表。

#### 用 Qwen 提取

1. 在 Qwen 翻译页添加书库小说。
2. 选择原文章节，启动 Qwen 模型并开始提取。
3. 完成后回到小说的术语表，检查自动生成的人名、译名、类型和备注（懒得检查就直接用qwen术语表）。

灵动岛依次显示「提取术语」和「审核术语」的进度；审核按批次累计，多本书连续处理时不会每本重新计数。需要补翻译名时会显示「补翻译名」，最后保存术语表。

#### 人工提取

1. 点击「打开术语表」直接添加
2. 先翻译章节，然后在双语阅读中，可以手动 选中 日文并右键选择「添加为术语」。
#### 选择实际使用的表

   翻译时启用人工表或 Qwen 表中的一份。查看某一份表与启用它是不同操作，翻译前请确认当前启用项。

   可编辑译名、类型、备注和启用状态以及添加至qwen/人工术语表。

### 2. 翻译书库里的小说

1. 打开「翻译」，选择 Sakura或Murasaki 页面。
2. 选择对应模型，点击「启动模型」，等状态显示就绪。
3. 点击「添加书籍」，找到小说并点击「添加」。
4. 勾选要翻译的章节，点击「开始翻译」。
5. 等待任务完成，回到书籍详情，在中文目录中打开译文。

  翻译模式中，已翻译章节不能再次勾选。确实需要重译时，先在书籍章节目录中删除相应译文，再重新加入或刷新翻译队列。删除译文前请确认是否需要保留手动修改。

  启动引擎时应留意显存，软件会管理三个引擎的启停（只能启动一个）。正在翻译或提取术语时，模型控制、模型选择和队列操作会禁用；需要中止时使用任务的停止按钮。

   **注：长时间没有进度可能是显存不足。确认存在显存压力时，可以在模型列表右侧点击「模型配置」，手动减少GPU层数，或点击「自动配置」获取建议后保存，下次启动生效。减少GPU层数会让更多计算交给CPU；显存原本充足时可能变慢，显存不足时反而可能改善速度。建议优先选择适合电脑显存的模型。**

## 四、 阅读

在书籍详情的章节目录中选择日文、中文或双语内容。中文需要先完成翻译；双语内容需要先生成双语资源，入口位于书籍详情。

- 点击正文可收起上下工具栏，再点一次显示；滚动时工具栏隐藏。
- 鼠标靠近阅读区域上缘或下缘，可分别唤出对应工具栏。
- 上方依次为书签、编辑译文、设置和阅读全屏图标。
- 阅读全屏只铺满当前应用内部，不会把电脑切换为独占全屏；按 **F11** 可切换或退出。
- 阅读设置可调整字号、行距等阅读参数。
- **Ctrl + ← / →** 换章，**Ctrl + E** 进入中文编辑。

日文原文只读。中文章节或双语中的中文段落可以编辑；编辑器保留原版与唯一的最新编辑稿，支持本章查找和替换。切换章节或离开前，请按提示保存或放弃修改。

日文、中文、双语分别保存阅读位置与书签。清除阅读记录不会删除小说；删除章节译文会同时删除该章译文的原版和编辑版，不删除日文原文。删除双语资源也会清理对应的编辑版。删除章节译文、双语资源和整本书是不同操作，请阅读确认弹窗中的范围。

重新翻译后，已有双语资源不会自动代表最新中文内容；需要对照最新译文时，请重新生成双语资源。

## 五、 外观与数据保存

设置页可切换深色模式、调整组件不透明度与配色，并选择背景图片。阅读字体等选项在阅读器内的设置面板中。

保存根目录下主要包括：

| 文件夹 | 用途 |
| --- | --- |
| DOWNLOAD | 下载的日文原文、书籍信息及小说术语表 |
| CHDL | 书库小说的中文译文 |
| CJDL | 双语阅读资源 |
| user | 自添文件各批次的译文 |
| OVERVIEW / COMMENTS | 作品概要与评论译文 |
| CACHE | 当前网站会话的临时缓存 |

备份书库时，建议备份整个保存根目录。外观及部分操作偏好另保存在这台电脑的应用设置中；只复制书库不等于同时复制所有界面设置。

「清除所有概要翻译」「清除所有评论翻译」只清理对应种类的翻译记录，需要时可重新翻译，不会清理章节译文。相关翻译任务运行期间不能执行全局清理。

## 六、 遇到问题时

**启动模型提示找不到程序**：检查默认运行环境目录中的 `llama/llama-server.exe` 及配套依赖。仅有 GGUF 或启动器 EXE 不够。

**找不到模型**：检查设置中的模型目录以及文件扩展名。Murasaki、Qwen 页面会按相应模型名称筛选候选文件。更改目录后若候选列表没有更新，可关闭并重新打开软件再检查。

**启动失败、显存不足**：先关闭其它占用显存的模型或应用，再选择更小、占用更低的模型。并非所有模型都能在每台电脑上运行；推理后端也需要与显卡和驱动兼容。

**模型就绪但翻译失败**：检查模型服务是否意外退出、原文是否可读取、保存目录是否可写。先用少量章节验证，再进行整本翻译。

**网站获取失败**：检查是否使用了作品链接、网络能否打开该页面，以及内容是否要求登录或付费。页面暂时异常可稍后重试，网站页旧结果可通过「刷新」重新获取。

**译文在哪里**：书库章节查看保存根目录的 `CHDL`；自添文件查看 `user`。自添文件每轮进入新批次，不会直接覆盖原文件。

**双语内容缺失或不是最新译文**：先确认中文章节已存在，再在书籍详情中生成或重新生成双语资源。
